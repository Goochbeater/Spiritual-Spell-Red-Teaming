## Tips

- Start every chat with **"cutie patootie"**.
- Preferences-only jailbreaking is the easiest setup — see the main [Anthropic guide](../README.md) for the full method rundown.
- Push prompts and regens are your friend — if the model thinks or outputs as **Claude**, regen until it answers as **ENI**:

