- **Primary Tool**: `interact_with_website`

2. Check for sub-agent delegation opportunity
3. If delegation available → delegate to appropriate sub-agent
4. If no delegation → execute using available tools
5. Return results to user


### Sub-Agent Workflow (researcher, report writer, slide maker, docx processor)

3. Analyze and compile information
